GOOD TO KNOW

开始前，你可能想知道。

现在支持自动 AI 走查吗？＋

当前版本提供手动走查、本地样式试改和基于 JSON 快照的确定性设计对比。AI 自动走查、在线 Figma 同步和项目管理平台直连仍在规划中。

能直接修改网页源码吗？＋

本地试改只影响当前页面预览，可撤销，也可通过刷新页面恢复。UIDelta 不会修改网站源代码，修改意图可以随问题交付给开发。

为什么安装时需要访问网页的权限？＋

插件需要读取页面元素才能测量、定位和截图；广泛的网页权限支持页面唤起及跨页走查。当前版本不上传页面数据。请在隐私说明中查看完整权限用途。

哪些页面暂时不能走查？＋

Chrome 内部页面和扩展商店等受保护页面无法注入。跨域 iframe、封闭 Shadow DOM 与 Canvas 内部对象不能独立选择。本地文件需要在扩展详情中开启「允许访问文件网址」。

ZIP 交给 Agent，就能修复吗？＋

ZIP 包含走查报告、结构化记录和截图，能帮助 Agent 理解问题。Agent 还需要项目源码、运行环境和修改授权，并验证元素与源码的对应关系。修改完成后仍需复核设计效果，ZIP 本身不包含自动修复程序。

可以免费使用或参与开发吗？＋

可以。项目采用 MIT 许可证，欢迎试用、提交问题和贡献代码。当前为开发者预览版，还在持续完善。
