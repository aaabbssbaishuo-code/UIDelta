# Changelog

## 0.9.4 — Open-source preview — 2026-09-03

First public packaging of the existing UIDelta v0.9.4 development source.

- Includes inspection, local style previews, issue evidence, local design comparison and HTML/XLSX/ZIP exports.
- Adds an annotation mark with selection handles, browser icons and reusable brand assets.
- Adds a static product website with an interactive, fictional review example.
- Adds Chinese/English documentation, privacy and permission details, contribution guidance and release automation.
- Adds three 1920×1080 campaign graphics and an Agent handoff guide describing the required project context.
- Retains existing regression suites for editing, layer properties, recording and export/message contracts.

This release is a developer preview installed as an unpacked extension. Online Figma sync and AI scanning are not included.
