# Roadmap

This is a direction of travel, not a dated delivery promise.

## Available in v0.9.4

- DOM inspection, spacing measurement and local style previews
- Element and region issue recording with evidence
- Local review sessions, issue search, editing and page anchors
- Manually imported Figma-style JSON comparison
- HTML, XLSX and ZIP handoff
- Open-source repository, product site, brand kit and reproducible packaging

## Next candidates

- Simplify permissions and evaluate an optional, user-activated access model
- Strengthen browser-level capture, persistence and export regression coverage
- Make design snapshot preparation easier and better documented
- Improve English localization and onboarding
- Refactor the large content script into focused modules while preserving zero-build installation

## Exploring

- Local rule-based checks for spacing and typography consistency
- Optional online design integrations with explicit user authorization
- Better mapping of evidence to existing issue-management workflows

AI scanning, cloud collaboration and automatic source-code edits are **not current features**. Proposals should start from a concrete design-review problem and document latency, privacy and verification tradeoffs.
