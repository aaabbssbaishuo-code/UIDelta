# HTML 交付报告重构 · 2026-09-04

## 范围与设计

使用 SaaS Product UI System skill。只改离线 HTML 导出模板及其交互，不改 XLSX / ZIP 数据契约、不改走查数据库、不覆盖用户已下载的报告。

面向开发与设计验收，采用紧凑报告密度：浅灰绿画布、白色内容面、橙色操作/定位点缀；完成状态使用绿色。正文 14px、问题标题 18px、项目标题 30px，控件复用统一边框、间距及焦点样式。

| 原样式 | 新结构 | 原因 |
| --- | --- | --- |
| 长 ISO 时间、重复描述与大量“未记录” | 简短时间；重复首行只保留一次；空技术字段不显示 | 优先阅读问题，不让模板占位淹没内容 |
| 所有 CSS 参数平铺 | 尺寸 / 坐标 / 测距前置；定位、布局、文字与外观收进“技术详情” | 默认简洁，开发仍可查看实际记录的信息 |
| 双图并排、截图裁切且留白过多 | 右列上下排列，等比完整显示，参考图加入同组 | 保留证据内容与一致的浏览顺序 |
| 图片仅尝试进入全屏 | 原生 dialog 弹窗、左右切换、计数、Esc / 遮罩关闭、失败重试 | 可控且支持鼠标、触屏和键盘 |
| 小型“已处理”复选框 | 至少 44px 高的状态按钮；整卡绿色底/边框/状态标识 | 完成反馈明显，再次点击可以撤回 |
| 仅有内容筛选 | 全部 / 待处理 / 已处理，完成进度与计数 | 便于逐项验收 |

按钮通常为 38px，完成状态按钮为 44px；760px 以下内容与截图转为单列，420px 以下操作区换行。技术内容可换行，页面来源保持单行并可查看完整链接。减少动态效果时禁用淡入与颜色过渡。

## 实现与边界

- 模板、样式、图标、卡片、分组、离线脚本拆为独立函数，位于 service-worker.js。
- 整个报告自包含：CSS、SVG 控件、位图及脚本均内嵌，无外部依赖。
- 图库仅切换当前问题的全景、细节、参考图；单图禁用翻页。
- 弹窗有焦点约束，关闭还原触发按钮与 body 滚动设置；异步图片晚到不会覆盖新图。
- 状态按会话保存，兼容同路径旧版布尔状态。不同导出子集不会删除其他问题状态。
- 本地存储不可用或 JSON 损坏时仍可标记、筛选和预览；提示导出状态留存。
- 状态导出继续使用 schemaVersion: 1。只导出当前报告内问题的状态。
- 原页面链接限 http/https；文本与属性转义；证据仅接受内嵌 PNG / JPEG / WebP / GIF。
- 不删除真实记录；状态修改仅属于当前离线报告，不回写插件。
- 不截断长描述：共用 firstLine 的 100 字限制不会造成整行丢失。
- 默认状态来自“已解决 / 已处理”；有本地状态时以本地布尔值为准。

## 自动化验证

新增 extension/html-report.test.mjs：解析实际生成的 HTML，再运行其内联脚本。DOM double 验证结构/交互，不冒充浏览器布局检查。

13 项专项用例均通过：

1. 文案去重、空占位删除、关键尺寸与技术分组。
2. 超长、多行描述完整性。
3. 当前附件匹配、参考图、单图与缺图。
4. HTML 转义、不安全 URL、非位图。
5. 完成 / 撤回、整卡样式、按钮、进度、计数和恢复。
6. 组合筛选、空态重置和焦点。
7. 存储损坏 / 拒绝、不同导出子集。
8. 旧状态、初始已解决、空报告。
9. 状态 JSON 契约、下载资源清理、导出失败。
10. 指定图片打开、左右键和按钮循环切换。
11. Esc / 遮罩关闭、焦点与滚动恢复、Tab 循环。
12. 图片异步竞争、失败重试、单图禁用按钮。
13. 响应式规则、44px 操作区、完成态及减少动态效果。

全量测试：155 / 155 通过。语法/资源检查通过。

## 实机检查限制

用户已允许打开独立本地预览，但 Browser Use URL 安全策略明确拒绝 file URL，禁止更换浏览器、代理 URL 或其他绕过路线。未进行真实浏览器布局与原生弹窗验收，不将自动化结果表述为视觉通过。

人工验收建议：

- 1280 / 768 / 320px 以及 200% 缩放：无水平溢出，描述可读，截图上下排列。
- 标记及撤回：整卡色调、边框、按钮和完成计数同步。
- 图片：等比无裁切，点击对应图；左右循环、Esc 关闭、焦点返回；背景不可滚动。
- 键盘：Tab 始终位于弹窗内，焦点清晰。
- 离线：重新打开文件可恢复状态；浏览器阻止本地存储时出现提示。
