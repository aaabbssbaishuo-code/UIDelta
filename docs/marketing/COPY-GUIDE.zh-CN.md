# UIDelta 文案基准

更新：2026-09-04。官网、GitHub、宣传图与发布介绍共用此表。

| 用途 | 定稿 |
| --- | --- |

English headline: **See the issue. Make the fix clear.**

English description: **Measure real web pages, record issues with evidence, and hand them to a developer or coding agent.**

## 写法

先写用户能完成什么，再说明功能。用一个具体例子贯穿故事：实际间距 24px，设计要求 16px；问题、截图和修改要求一起交付。

每张图只讲一个主题。主标题简短，辅助文案解释原因，细节留在正文或说明中。中文主页面直接使用中文原稿；英文独立维护，不依赖浏览器自动翻译。

按钮写清动作：免费下载 UIDelta、复制给 Agent 的提示词、下载完整宣传包。不写含糊的「立即体验」来代替实际安装步骤。

## 能承诺什么

- 直接在真实网页上手动测量、记录与取证。
- HTML、XLSX 和 ZIP 三种交付。
- Agent 在有项目源码、运行环境和修改授权时，可依据报告与截图辅助定位、修改和复核。

当前不能承诺「一键修好所有问题」「零上下文自动改源码」「在线 Figma 自动同步」或「已上架扩展商店」。不编造效率百分比、用户规模、评价或客户背书。
