# UIDelta 商店介绍

可复制文案。当前为开发者预览版，尚未上架 Chrome 应用商店。

## 名称

UIDelta — 网页走查与问题记录

## 简短说明

在真实网页上测量、记录、取证。把一句「这里不对」，变成一份开发看得懂的走查报告。

## 完整介绍

看见问题。说清怎么改。

按钮间距大了，标题字号小了，卡片和设计稿不一致了。发现问题之后，你需要把它说清楚。

UIDelta 让你直接在真实网页上测量、记录、取证。哪里有问题，要改成什么，截图和元素位置都跟着记录留下来。交给前端时，少一次追问。

**差多少，直接量。**
点选元素，查看尺寸、字体、颜色、盒模型与间距。在当前页面试改样式，确认修改方向。试改可撤销，刷新后恢复，不修改网站源码。

**问题在哪，证据就在哪。**
选中一个元素，或框选一片区域，写下修改要求。记录保留问题描述、页面全景、元素细节与定位信息；支持分类、优先级和影响程度，方便整理与跟进。

**记录一次，接着改。**
HTML 协作问题单，打开就能看；XLSX 排期问题表，方便安排修改；ZIP 把报告、结构化记录和截图一起交给前端或 Agent。

把 ZIP 放进项目，让具备源码、运行环境与修改授权的 Agent 根据证据查找对应实现，按明确的设计要求修改，再回到网页复核。

**你的页面，留在你的浏览器。**
无需账号，无需 API Key。当前版本把走查数据保存在本地，不向外部服务器发送。项目采用 MIT 许可证，免费开源。

适合设计师做页面验收，也适合前端、产品和测试同学沟通视觉问题。

开始使用：打开目标网页，唤起 UIDelta，点选元素查看信息；发现问题后记录，在交付面板选择 HTML、XLSX 或 ZIP 导出。

当前设计对比需要手动导入 Figma Frame JSON 快照。AI 自动走查和在线 Figma 同步仍在规划中。Chrome 内部页面、扩展商店等受保护页面无法使用。
