# UIDelta 产品与商店介绍草稿

这份文案依据 UIDelta 当前功能撰写，可用于 GitHub、产品介绍与后续商店提交。它不表示产品已经上架商店。

## 名称

UIDelta — 网页走查与证据交付

## 短描述

在真实网页上测量、记录、取证，导出 HTML、XLSX 或 ZIP，把设计反馈交给前端与 Agent。

## 完整介绍

把一句「这里不对」，变成一份开发看得懂的走查报告。

UIDelta 是面向 UI 设计师与前端团队的网页走查工具。直接在正在验收的页面上查看尺寸和样式、测量间距、试改效果；发现偏差时，留下问题描述，让截图、元素位置与实测信息跟着记录一起保存。

走查结束，根据接收者选择交付方式：用 HTML 查看和跟进问题，用 XLSX 整理排期，或把 ZIP 证据包交给前端与编码 Agent，继续定位和修改。

### 在页面上看清实现

选择元素，查看宽高、布局、字体、颜色、圆角、透明度与盒模型等属性。按住 Option / Alt 测量元素间距，结合页面结构判断偏差的位置。

需要确认修改方向时，可以在当前页面试改支持的样式和文本，再撤销或刷新恢复。本地试改用于预览，不会直接改动网站源代码。

### 记录问题，同时留下证据

选中元素或框选区域，写下问题与修改要求，选择问题类型、优先级和影响程度。页面全景、元素细节、页面地址与元素锚点随记录保存，也可以插入参考图片。

在问题清单里搜索、筛选、编辑、删除与定位记录，方便逐项整理走查结果。

### 一份走查，三种交付

HTML 协作问题单：把问题描述、截图与页面上下文放在一起，便于离线查看、筛选和跟进。

XLSX 排期问题表：以表格整理问题与截图预览，并提供负责人、处理状态和修复版本等字段，接入已有排期流程。

ZIP 证据包：包含 report.md、issues.json 和截图资源。前端或 Agent 可以结合项目源码，根据页面、元素选择器、文本、样式和图片验证对应实现，再按明确设计要求修改与复核。

交付前，可以悬停「示例」查看三种格式的用途，也可以复制摘要给 Codex。

### 本地运行，按需交付

无需账号或 API Key。当前版本的走查记录和截图保存在扩展本地，不向外部服务器上传；你可以自行选择导出的文件和接收者。

### 适用场景

- UI 设计师：实现验收、视觉还原检查、修复后复查。
- 前端开发：理解具体设计要求，核对元素、样式与截图。
- 产品与测试：记录页面问题，把验收反馈整理为可跟进的清单。

### 如何开始

1. 安装并开启 UIDelta，在可访问的普通网页开始走查。
2. 选择元素，查看属性、测量间距，按需试改样式。
3. 按 R 记录问题，补充描述，等待证据就绪后保存。
4. 在问题清单整理记录，选择 HTML、XLSX 或 ZIP 交付。
5. 修改完成后回到网页，逐项复核。

### 当前能力边界

当前为 Chrome 开发者预览版，通过解压加载使用。Chrome 内部页面、扩展商店等受保护页面无法注入。

设计快照对比需要手动导入 JSON；在线 Figma 同步、AI 自动走查和项目管理平台直连尚未提供。Agent 修复需要项目源码、运行环境和修改授权，UIDelta 本身不会自动修改源码。
