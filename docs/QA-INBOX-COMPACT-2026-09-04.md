# 问题清单紧凑排版

## 本轮调整

- **页面来源**：单行“页面 · 页面名”，超长省略；不再另起一行展示路由。完整名称和路由保留在 title／无障碍标签中。
- **右对齐**：旧卡片继承 `align-items:start`，操作区仅有内容宽度；改为卡片子项 stretch、操作区宽度 100%，内部 flex-end。保留 32px 点击区和图标提示。
- **搜索**：32px 内凹搜索框、14px 标准 SVG 放大镜、12px 常规字重、明确焦点环；“搜索问题”占位，带清除按钮。清除不改变当前筛选和交付勾选。
- **截图**：参考用户图 2，改为全景主图和右下细节叠放，橙色角标；截图区 76px，主图 70px、细节 48px。等比 contain，点击或键盘仍可分别打开原图；单图占满，不留空槽。
- **卡片**：内边距 10→8px、内容间距 9→6px、底部操作间距收紧；标题仍为 13px，不裁掉问题描述。
- **反馈**：普通删除／取消提示 3.2 秒后收起，避免常驻标题区；失败说明持续显示，旧计时器不能清掉新错误。

沿用 `saas-product-ui-system` 的紧凑工具型界面规则：先压缩留白，不通过缩小正文或点击区实现紧凑。现有橙色／灰绿主题、倒计时删除、清空与卡片补位保持不变。
