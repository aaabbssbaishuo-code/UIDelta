# UIDelta 产品定义

## 一句话

UIDelta 是为 UI 设计师打造的浏览器走查与证据交付工具：在真实页面上测量、记录问题，把描述、截图、样式和位置一起交给开发。

品牌主张：**每一处偏差，都有据可查。**

英文短介绍：**Open-source UI inspection, issue capture and evidence handoff for designers.**

## 用户与使用时机

主要用户是负责实现验收的 UI / 产品设计师；协作对象是修复页面问题的前端工程师。典型时机是新功能验收、版本发布前检查和修复后的复查。插件补充现有项目管理流程，以导出文件交付。

## 需要解决的问题

发现一个不符合设计的地方后，设计师仍需要量尺寸、截图、标注、记页面地址、解释修改意图。分散的信息既增加记录成本，也让开发反复询问上下文。

UIDelta 的核心对象是一条有证据的 Issue，而非孤立的尺寸提示。主流程为：**发现 → 记录 → 整理 → 交付**。

## 可对外传播的能力

基于当前源码的能力清单与边界已收录在中英文 README。宣传重点为测量、原位记录、自动截图与多格式交付。次级能力为本地样式试改、设计 JSON 快照对比。

不使用无法验证的节省时间比例、用户数量或“自动发现所有 UI 问题”等表述。不宣传已经接入 AI、Figma 在线 API 或项目管理平台。

## 品牌与页面规格

- 标识：选区锚点与标注便签组合，突出“选中页面元素并留下问题”的动作。
- 主色：Delta Orange `#F2603D`；深色 `#272A28`；背景 `#F8F8F4`。
- 宣传页为舒适密度；演示面板为紧凑密度。字号、间距和实际工作流承担视觉层级。
- 字体：系统无衬线优先，中文使用系统中文字体；数值和技术字段采用等宽字体，不依赖远程字体。
- 页面顺序：产品主张 → 三步交互演示 → 工作流 → 功能 → 本地数据 → 安装 → 常见问题。
- 主行动为下载插件，次行动为了解流程与阅读源码。
- 演示明确标记为虚构数据；提供测量／记录／交付界面切换、原图查看和 Markdown 示例下载。
- 布局适配桌面和平板，手机将演示面板改为纵向排列。原生按钮、details、焦点样式与 reduced-motion 均保留。
