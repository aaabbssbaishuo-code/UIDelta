# UIDelta 编辑器主题

当前主题依据用户提供的橙色标志与灰绿编辑器参考图；只改变插件界面，不改变被测页面及报告中的实测颜色。

| 用途 | 颜色 |
| --- | --- |
| 主操作、选中提示 | `#F2603D` |
| 面板 | `#222423` |
| 输入与卡片 | `#2E312C` |
| 内嵌背景、模式栏 | `#1B1D1C` |
| 正文 | `#F2F3ED` |
| 辅助文字 | `#C1C6B8` |
| 次级文字 | `#ADB5A2` |
| 尺寸提示底色 / 文字 | `#FFF0E8` / `#5C2A1E` |

- 入口：`extension/content.js` 的 `brandThemeStyles()`，在既有组件样式之后加载。弹窗配色在 `extension/popup.css` 中保持一致。
- 控件采用 4px 圆角，面板采用 8px 圆角；沿用 250 × 560px 面板约束与 28px 常规输入控件，不变更拖动、焦点、键盘及记录行为。
- 主按钮使用深色文字，默认橙色底上的文字对比度约 5.26:1。辅助文字有所提亮，不照搬参考图中过淡的小字。
- 保留测距、成功、警告和错误的语义颜色；不要把实际采样的色块替换为品牌色。
- `npm test` 包含主题取色、一致性、对比度、样式加载顺序和原有交互回归测试。这些是自动化检查，不等同于浏览器视觉验收。

## 紧凑按钮、固定操作区与交付示例

- `compactSurfaceStyles()` 统一普通操作按钮为 28px 高、12px 字号、8px 水平内边距；模式栏仍保留独立的图标点击区域。沿用既有橙色与灰绿配色。
- 检查页和交付页采用占满可用高度的纵向布局：内容容器独立滚动，页脚 `flex:none`，不依赖覆盖内容的绝对定位或滚动到底部才出现的按钮。
- 插件根、Shadow DOM 顶层界面和 popup 使用 `translate="no"`、`notranslate` 与 `lang="zh-CN"`。检查按钮移除重复快捷键字符，快捷键保留在底部提示。截图中出现的“法典 / 职位代理 / 忏悔”等并非源码文案，疑似页面自动翻译结果；不修改被测网页的翻译设置。
- 每张交付卡片的入口简化为“示例”。悬停 180ms 或键盘聚焦即可在旁边查看图片，不遮罩整页、不抢焦点；移到图片内保持，移开后收起，Esc 只关闭这层预览。点击仍可打开大图，兼容触屏。图片原样取自用户提供的 `release/UIDelta-delivery-previews.zip`，使用 `extension/previews/*-preview@2x.png`。内置示例仅说明交付形式，不混入真实问题或导出证据。
- 示例复用图片预览窗口，支持前后切换、键盘与关闭回焦；加载失败有提示，过期请求不覆盖新图。worker 仅允许 `html / xlsx / zip` 三种预设名称，返回本地 PNG，不接受 URL 或路径参数。
- `scripts/build.mjs` 纳入三个内置图片，`scripts/check.mjs` 检查图片存在。新增 `delivery-preview.test.mjs`，验证图片、异步状态、原截图兼容、按钮尺寸与页脚结构。依然不等同于浏览器目测验收。

## 保存计数、盒模型与扩展 Logo

- 工具栏数字只统计正式保存的问题（兼容没有 `reviewStatus` 的旧记录），草稿仍保留在问题清单中，悬停提示单独说明草稿数量。保存失败、编辑已保存问题、初次加载与删除不播放增量动画。
- 新增保存成功后立即返回检查；数字在 280ms 内上滚，辅以橙色扩散圈及短暂的 `+1`。采用 Emil skill 的 `transform` / `opacity` 原则，按钮本身不缩放、不改尺寸、不抢焦点；减少动态效果时只渐隐。快速重复、切换、收起、截图及工具栏拖动会清理旧动画。
- 按 SaaS UI skill 的信息优先级组织属性：先尺寸、布局、文字和外观，后图层盒模型。盒模型参照 DevTools 的外边距 / 边框 / 内边距 / 内容四色分层，使用独立语义色，不受品牌背景覆盖。四向外边距保留负数、小数与未解析的 `auto`，不计入内容尺寸扣减。
- 本机加载目录原先没有 `icons` 资源及 manifest 图标声明，因此 Chrome 显示默认字母图标。已接入现有新版橙色标志的 16 / 32 / 48 / 128px PNG，扩展菜单与工具栏共用；与仓库资源逐个比对一致，未改变权限和版本。
- `save-feedback.test.mjs` 验证真实保存路径、计数与可取消动画、减少动态效果和图标资源；盒模型测试补充顺序、配色、负外边距及 `auto`。本轮代码备份：`<temporary-backup-directory>`。尚未在用户的实际网页做浏览器目测验收。
