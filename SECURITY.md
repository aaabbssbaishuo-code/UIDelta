# Security reporting

UIDelta processes local page content, screenshots, imported JSON and report files. Potential vulnerabilities include unsafe HTML export, untrusted message handling and access to other sessions' evidence.

Please use GitHub's private vulnerability reporting feature under **Security → Report a vulnerability** if it is available. Otherwise contact the maintainer through the contact options on their GitHub profile. Avoid publishing private page data, live credentials or exploit details in a public issue. Public issues can describe a general concern without sensitive details.

The project is currently maintained as a developer preview; no security audit or response-time guarantee is claimed. Fixes target the latest version.
