# 新版 UIDelta 界面截图

截图使用当前 `extension/content.js` 和其样式，运行在虚构的 Orbit 页面上。面板的文字、按钮、选项和布局直接来自产品代码。

- `workspace-inspect.png` / `panel-inspect.png`：测量与本地试改。
- `workspace-record.png` / `panel-record.png`：问题描述、截图、类型与优先级。
- `workspace-delivery.png` / `panel-delivery.png`：三种交付与内置示例入口。
- `canvas-measure.png`：24px 卡片间距测量。
- `toolbar.png`：当前紧凑工具栏。
- `SOURCE.json`：渲染时间、源码校验值、视口与数据来源。

完整页面截图为 2560 × 1520（1280 × 760 CSS px 的 2× 导出），常规面板为 500 × 1120（250 × 560 CSS px 的 2× 导出）。

使用 `extension/test-harness.html` 的内存桥接提供虚构会话。截图证据来自示例网页的渲染，不涉及用户真实网页或账户。这组图验证宣传材料与当前 UI 的一致性，不证明浏览器扩展的真实截图、持久化或导出链路通过验收。
