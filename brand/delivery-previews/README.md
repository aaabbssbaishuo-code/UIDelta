# 三种交付，一眼看懂。

| 格式 | 主标题 | 内容 |
| --- | --- | --- |
| HTML | 打开，就看懂。 | 截图与修改要求：24px → 16px |
| XLSX | 排好，逐项改。 | 问题、优先级与状态 |
| ZIP | 打包，交给 Agent。 | 报告、定位、截图，结合项目源码继续处理 |

每张包含 270×164 PNG、540×328 的 @2x PNG，以及可编辑 SVG。用于悬停、键盘聚焦或点击时展示的功能示意，采用简化界面与虚构数据。

打开 index.html 可查看交互演示和下载。按 Esc 关闭预览，手机轻点查看。官网交付卡片也使用这三张图。扩展内使用 extension/previews/ 的 @2x 副本。

ZIP 不包含项目源码或自动修复程序。Agent 需要项目源码、运行环境及修改授权，修改后仍需复核。
