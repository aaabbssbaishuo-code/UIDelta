# UIDelta · 16:9 宣传设计

三张 PNG 均为 **1920×1080**：

1. `cover-16x9.png`：产品封面——每一处偏差，都有据可查。
2. `feature-inspect-16x9.png`：直接在真实网页上测量、记录、取证。
3. `feature-delivery-16x9.png`：HTML / XLSX / ZIP，交付给前端和 Agent。

同名 HTML 与 `campaign-16x9.css` 是可编辑设计源文件。保持文件位置不变，在浏览器中打开 HTML 即可查看；按 1920×1080 视口截取可重新导出。字体使用系统中文字体，不依赖远程字体下载。

`icon.svg` 和 `mark.svg` 是新版标注 Logo。品牌色为 `#F2603D`，标识结合选区锚点与标注便签。

界面与代码均为虚构示意。Agent 需要项目源码、运行环境及修改授权，不能仅靠 ZIP 保证自动修复。`AGENT-HANDOFF.md` 提供实际交接方法与可复制的提示词。

发布时可搭配这句介绍：

> UIDelta 是为 UI 设计师打造的开源走查工具。直接在真实网页上测量、记录、取证，把一句「这里不对」，变成一份开发看得懂的走查报告。
